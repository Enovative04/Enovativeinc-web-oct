# Enovative Inc Website — Structure & Copy

This document is the working copy and information-architecture document for the Enovative Inc website.

The existing website features and interactions must be preserved unless explicitly marked for change. This update focuses on:
- Updating the copy to the current Enovative positioning.
- Reorganising the information architecture around the current business.
- Adding pages that are part of the intended Enovative ecosystem.
- Preserving existing animations, interactions, forms, case-study behaviour, navigation behaviour, WhatsApp behaviour, and other implemented features.
- Ensuring no important Enovative business information is lost or reduced to generic agency copy.

## How to use this document

- Edit the wording under the relevant page or section heading.
- Keep headings and labels in place so it is clear where each change belongs.
- To remove a line, write `[REMOVE]` beside it rather than deleting its label.
- To add new content, add it under the closest matching section and label it clearly.
- This document is a reference; editing it does not automatically change the live website.
- If only a visual/design change is required, describe that separately rather than changing the copy here.
- Existing functionality should not be removed simply because the copy or page structure is being updated.

# 1. Website structure

## Shared site elements

- **Header/navigation:** Fixed glass-morphism rounded header with a slightly enlarged Enovative Inc logo, navigation links, the Enovative Room SVG logo link, and a “Start a Project” action. On smaller screens, navigation opens as a full-screen menu.
- **Floating WhatsApp button:** Fixed at the bottom-right of every page; opens a WhatsApp chat with Enovative Inc.
- **Image and button treatment:** Content images use rounded corners except for the full-bleed hero and the opportunity-section background; buttons use rounded rectangles.
- **Footer:** Shared across the home page and subpages; includes positioning, short description, navigation links, contact details, ecosystem links, legal links, and copyright.
- **Project case-study popups:** Open when a featured project on the home page is selected.
- **Existing page transitions and animation behaviour:** Preserve all current implemented interactions. Copy/IA changes should not remove them.

## 01 — University of Investors

- **Category:** Education / Investment
- **Featured summary:** We clarified the promise, built an investor-learning language and designed a system that makes ambition feel practical.
- **The Challenge:** A growing education venture needed to feel credible to students, parents and first-time investors.
- **The Insight:** People trust financial education faster when the brand feels structured, generous and future-facing.
- **The Strategy:** We clarified the promise, built an investor-learning language and designed a system that makes ambition feel practical.
- **The Solution:** Positioning, messaging, identity direction and a scalable digital experience.
- **Results:** Improved trust; Better engagement; Stronger positioning

- **Category:** Fashion / Retail
- **Featured summary:** We turned the brand into a belief system that could work across product drops, social content and retail moments.

- **The Insight:** The audience needed to see care, craft and conviction before they saw the catalogue.
- **The Strategy:** We turned the brand into a belief system that could work across product drops, social content and retail moments.

- **Results:** Increased inquiries; Improved trust; Higher perceived value
